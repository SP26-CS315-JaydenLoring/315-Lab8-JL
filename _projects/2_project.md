This project uses an **Arduino Uno** and an **HC-SR04 ultrasonic sensor** to measure distance in real time and respond with visual and audio alerts.

### Features
- Measures object distance continuously
- Displays distance on an LCD screen
- Uses LEDs to show safe vs warning status
- Activates a buzzer when an object gets too close

### Components
- Arduino Uno
- HC-SR04 ultrasonic sensor
- LCD1602 display
- LEDs
- Buzzer
- Breadboard and jumper wires

### What I learned
This project helped me understand sensor input, conditional logic, hardware wiring, debugging, and the basics of embedded systems design.
