This project is a command-line application built with **Node.js** that connects to the **GitHub API** and generates useful information about a user's repositories.

### Features
- Fetches GitHub user data
- Analyzes repository information
- Displays top repositories by stars
- Generates Markdown reports
- Uses input validation and modular code structure

### Tools Used
- Node.js
- JavaScript
- Axios
- dotenv
- Joi
- GitHub REST API

### What I learned
This project helped me practice API integration, error handling, modular architecture, and command-line workflow design.
