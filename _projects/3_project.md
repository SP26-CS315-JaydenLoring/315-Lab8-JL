This website is a customized **Jekyll portfolio** built from the al-folio theme and adapted to reflect my background, interests, and technical work.

### Features
- About page with personal and academic background
- Project cards for software and hardware work
- Resume/CV data section
- GitHub Pages deployment

### Tools Used
- Jekyll
- Markdown
- YAML
- GitHub Pages

### What I learned
Through this project, I learned how static site generators work, how to customize structured content, and how to publish a professional site with GitHub Pages.
